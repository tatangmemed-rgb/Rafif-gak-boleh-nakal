# 🎮 Rafif Gak Boleh Nakal

Game Tic Tac Toe sederhana untuk Android.

## Fitur
- 1 Player melawan komputer 🤖
- 2 Player 👥
- Papan 3x3, 4x4, 5x5, 6x6, 7x7
- Ketuk kotak kosong untuk bermain
- 😊🥳 untuk pemenang
- 😭😢 untuk yang kalah
- 🤝😄 jika seri

## Cara membuat APK lewat GitHub
1. Buat repository baru di GitHub.
2. Upload semua isi folder proyek ini.
3. Buka tab **Actions**.
4. Pilih workflow **Build Android APK**.
5. Jalankan workflow jika diperlukan.
6. Setelah selesai, buka hasil workflow.
7. Unduh artifact **Rafif-Gak-Boleh-Nakal-APK**.
8. File `app-debug.apk` adalah APK yang dapat dipasang di Android.

Catatan: APK debug biasanya dapat memunculkan peringatan keamanan Android saat dipasang karena bukan dari Play Store.
